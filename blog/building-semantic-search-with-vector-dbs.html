Building Semantic Search in 10 Minutes

Python Tutorial OpenAI

In the previous post, we discussed the theory behind vector databases. Today, we're going to write code. We will build a semantic search engine that can search through a set of documents based on their meaning rather than exact keywords.

The Stack

  • Language: Python 3.10+
  • Embeddings: OpenAI API (text-embedding-3-small)
  • Vector Database: ChromaDB (Runs locally, no setup required)

1. Setup and Dependencies

First, let's install the necessary packages. You'll need an OpenAI API key for this.

pip install chromadb openai python-dotenv

2. Initializing the Database

ChromaDB is fantastic for prototyping because it can run entirely in-memory or save to a local sqlite file. Let's set it up and create a "collection" (similar to a table in SQL).

import chromadb
from openai import OpenAI
import os

# Initialize OpenAI client
client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

# Initialize ChromaDB locally
chroma_client = chromadb.PersistentClient(path="./chroma_db")
collection = chroma_client.get_or_create_collection(name="my_documents")

3. Generating Embeddings and Ingesting Data

We need some sample data. Let's take a few sentences about different topics. We'll generate an embedding for each sentence using OpenAI, and then store the text alongside its vector representation in ChromaDB.

documents = [
    "The new Mars rover collected rock samples from the crater.",
    "Apple announced their latest M4 silicon chips today.",
    "Baking sourdough bread requires a good starter and patience.",
    "SpaceX successfully landed another reusable rocket.",
    "A simple recipe for chocolate chip cookies."
]

# Helper function to get embeddings
def get_embedding(text):
    response = client.embeddings.create(
        input=text,
        model="text-embedding-3-small"
    )
    return response.data[0].embedding

# Ingest data
for i, doc in enumerate(documents):
    vector = get_embedding(doc)
    collection.add(
        embeddings=[vector],
        documents=[doc],
        ids=[f"doc_{i}"]
    )
    
print("Ingestion complete!")

4. Performing Semantic Search

Now for the magic. We're going to search for something that doesn't share any exact keywords with our dataset. Let's search for "space exploration".

query = "advancements in space exploration"
query_vector = get_embedding(query)

results = collection.query(
    query_embeddings=[query_vector],
    n_results=2 # Get top 2 results
)

print(f"Query: {query}\n")
for doc in results['documents'][0]:
    print(f"- {doc}")

The Output:

Query: advancements in space exploration

- The new Mars rover collected rock samples from the crater.
- SpaceX successfully landed another reusable rocket.

Conclusion

Notice how our query "advancements in space exploration" didn't contain the words "Mars", "rover", or "SpaceX", yet the database accurately retrieved the two space-related sentences. This is the power of vector search.

In a production scenario, you would swap ChromaDB for a distributed vector store like Milvus or Pinecone, and add chunking strategies for larger documents. But the core principle remains exactly the same.
